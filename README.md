# rainfocus-page

Static build of a RainFocus event-setup page from a Figma design. Made with SvelteKit 3, Svelte 5 and SCSS.

## Run

    npm install
    npm run dev

## Build

    npm run build
    npm run preview

## Layout

- `src/routes/+page.svelte`: the page
- `src/lib/styles/`: design tokens and global styles
- `src/lib/assets/`: SVGs exported from Figma
